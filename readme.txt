Консольное приложение для поиска фильмов. Ищи по названию, жанру или году выхода — результаты выводятся постранично, а история запросов сохраняется автоматически.

Установка
pip install -r requirements.txt
Создай файл .env в корне проекта:
# MySQL
SQL_HOST=localhost
SQL_USER=root
SQL_PASSWORD=your_password
DB_NAME=movies_db

# MongoDB
MONGO_URL=mongodb://localhost:27017
MONGO_DATABASE=movies_logs
MONGO_COLLECTION=search_queries
Запуск:
python main.py

Что умеет приложение
Поиск по названию — вводишь слово или фразу, приложение находит все подходящие фильмы и показывает их по 10 штук.
Поиск по жанру — выбираешь жанр из списка, получаешь все фильмы этой категории.
Поиск по году — задаёшь диапазон лет, приложение само подскажет, какие годы есть в базе.
Топ-5 запросов — показывает самые популярные поиски: сколько раз выполнялся запрос и когда последний раз.

Стек

MySQL — хранит фильмы
MongoDB — хранит историю поисков
PyMySQL, pymongo, python-dotenv
